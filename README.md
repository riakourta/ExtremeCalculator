Οδηγός Χρήσης Git για την Ομάδα

Συγχρονισμός (Pull): Πριν ξεκινήσεις τη δουλειά, άνοιξε το IntelliJ IDEA, πήγαινε στο μενού του Git και κάνε Pull στο main branch. Έτσι βεβαιώνεσαι ότι έχεις τον πιο πρόσφατο κώδικα.

Δημιουργία Branch: Δεν γράφουμε ποτέ κώδικα απευθείας στο main. Φτιάξε ένα νέο branch με ονομασία βασισμένη στο task σου, π.χ. feature/task-2-gui ή feature/task-4-history.

Αποθήκευση (Commit): Όταν ολοκληρώσεις ένα λογικό κομμάτι κώδικα, κάνε Commit. Στο μήνυμα γράψε ξεκάθαρα τι έφτιαξες και πρόσθεσε τον αριθμό του Issue σου (π.χ. "Προσθήκη λίστας νομισμάτων, Resolves #2") για να κλείσει αυτόματα η κάρτα στο Project Board.

Ανέβασμα (Push): Κάνε Push το branch σου στο GitHub.

Ενσωμάτωση (Pull Request): Μπες στη σελίδα του GitHub, άνοιξε ένα νέο Pull Request και όρισε εμένα ως Reviewer. Δεν πατάει κανείς Merge στον δικό του κώδικα. Ο έλεγχος και η τελική ενσωμάτωση στο main γίνεται αποκλειστικά από εμένα για να αποφευχθούν τα merge conflicts.
